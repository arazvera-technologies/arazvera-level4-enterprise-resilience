# How to Engage ARAZVERA Level 4

## Suitable scoped engagements

- Architecture and reliability reviews for Python/FastAPI, PostgreSQL and API-integrated backends.
- Secure multi-tenant data access design and negative tests.
- Transactional outbox, reliable event processing and independent worker recovery.
- Staging Canary design, bounded fault injection and rollback/runbook engineering.
- Incident observability, alert integration planning and recovery validation.

## Delivery sequence

1. Scope the customer-owned infrastructure, known failure scenario, access permissions and acceptance requirements.
2. Reproduce the issue in an authorized isolated environment, with measurable baseline observations.
3. Deliver reviewable source changes and automated tests; never operate outside approved project boundaries.
4. Validate negative cases, failure/recovery outcomes, operational evidence and conservative release criteria.
5. Hand over English technical documentation, deployment assumptions, unresolved risks and customer acceptance records.

## Terms and confidentiality

Contracts can be structured as accepted milestones or time-and-materials according to a written proposal. Hosting, third-party APIs, production credentials and licenses remain customer-owned and are separately approved. The public portfolio does not guarantee pricing, delivery dates, independent security certification or acceptance into any specific customer's environment.

Private engineering source is disclosed only through appropriately authorized project review and license terms. This public repository deliberately does not contain the proprietary implementation.
